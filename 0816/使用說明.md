# Google Generative AI API 設定說明

## 錯誤原因

您遇到的錯誤：`Google Generative AI API key is missing`

這是因為程式需要 Google Gemini API key 才能使用 AI 功能。

## 解決步驟

### 1. 取得正確的 API Key

請前往 Google AI Studio 取得 API key：
- 網址：https://aistudio.google.com/app/apikey
- 登入您的 Google 帳號
- 點選「Create API key」
- 複製產生的 API key（格式類似：`AIzaSy...` 約 39 字元）

### 2. 設定 API Key

**方法一：使用 .env 檔案（推薦）**

在您的專案目錄建立或編輯 `.env` 檔案：

```bash
GOOGLE_GENERATIVE_AI_API_KEY="您的真實API_Key"
GEMINI_API_KEY="您的真實API_Key"
```

**方法二：在程式中直接設定**

```python
import os
os.environ['GOOGLE_GENERATIVE_AI_API_KEY'] = '您的真實API_Key'
```

### 3. 安裝必要套件

```bash
cd /home/pi/Documents/github/20260809michael
uv pip install google-generativeai python-dotenv
```

### 4. 使用範例

```python
import os
import google.generativeai as genai

# 從環境變數讀取 API key
api_key = os.getenv('GOOGLE_GENERATIVE_AI_API_KEY')

# 設定 API
genai.configure(api_key=api_key)

# 使用模型
model = genai.GenerativeModel('gemini-pro')
response = model.generate_content("你好！")
print(response.text)
```

### 5. 在 Jupyter Notebook 中使用

在筆記本第一個 cell 加入：

```python
import os
from dotenv import load_dotenv

# 載入 .env 檔案
load_dotenv()

# 或直接設定
os.environ['GOOGLE_GENERATIVE_AI_API_KEY'] = '您的真實API_Key'
```

## 注意事項

⚠️ **重要**：
- API key 是機密資訊，不要上傳到 GitHub 或公開分享
- 將 `.env` 加入 `.gitignore` 檔案
- 目前 `.env` 中的 key 似乎格式不正確，請取得新的有效 key

## 常見問題

**Q: 錯誤訊息：API_KEY_INVALID**  
A: API key 格式不正確或已過期，請重新取得

**Q: 錯誤訊息：ModuleNotFoundError**  
A: 套件未安裝，請執行 `uv pip install google-generativeai`

**Q: 如何在不同環境使用？**  
A: 建議使用 `.env` 檔案，並在每個專案目錄都放一份
